# 各优化项预估提升分值参考

## 行业基准分值区间（参照系数据来源）

报告"核心结论"中的参照系说明（"同类网站通常在 X～X 分区间"）**使用以下基准值**，而非 Claude 每次临场估算，以确保跨诊断可比性。

| 行业类型 | 典型得分区间 | 说明 |
|---------|------------|------|
| 出海营销 / 广告服务 | 40～65 分 | 内容侧权重高，多数企业官网事实密度不足；头部企业约 65～75 分 |
| SaaS / 软件产品 | 45～70 分 | 技术侧配置较好但内容侧常缺乏可引用深度内容；头部约 70～80 分 |
| 混合型（出海营销+SaaS） | 42～65 分 | 两类特征叠加，平均水平约 50～60 分 |
| 跨境电商 | 35～60 分 | 商品信息丰富但公司主体事实密度低；头部约 60～72 分 |
| 企业服务 / 咨询 | 45～68 分 | 内容质量参差，白皮书类深度内容加分显著 |
| 品牌 / 消费品 | 30～58 分 | 视觉主导、可爬取文字少；AI 理解挑战较大 |
| 金融 / 投资 | 38～62 分 | 合规限制导致内容谨慎，可引用事实少 |
| 医疗 / 健康 | 35～60 分 | 类似金融，深度内容受限 |
| 通用默认 | 40～65 分 | 行业识别不明确时使用 |

> **使用说明**：在报告核心结论中，按识别到的行业类型填入对应区间，并判断目标网站处于"上游 / 中游 / 下游"。以混合型（出海营销+SaaS）为例，区间为 42～65 分，得分 58 分则处于中游偏上。

## 使用说明

本表为 Step 8 优化建议中"预估提升分值"的参考锚定，避免每次诊断估值不一致。

**使用方式**：根据目标项目当前得分和行业权重，从参考区间中取值。
- 当前得分越低、行业权重越高，提升空间越大，取区间上限
- 当前得分已较高（6～7 分），提升空间有限，取区间下限
- **直接使用表格中"典型综合提升"列的数值**，该列已换算为综合评分（满分 100）的最终提升幅度，无需额外计算

## 说明事项

1. **叠加效应**：多个优化项同时实施时，实际提升分通常略低于各项之和（评分有自然上限）
2. **行业权重影响**：内容侧权重高的行业（如企业服务 50%），内容侧优化的综合提升分相应更大
3. **基准分影响**：当前综合评分越低（如 40 分以下），同等改动带来的综合提升越显著
4. **参考区间的用途**：仅作为估值锚定，实际提升因网站具体情况而异，报告中应以"约 +X～X 分"形式呈现，不给精确单值
