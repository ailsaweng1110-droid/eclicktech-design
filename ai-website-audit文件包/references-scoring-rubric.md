# 评分细则（Scoring Rubric）

> 本文件被 SKILL.md Step 6 引用，详细定义每个评估项的分值锚点。

---

## 设计侧

### 语义化 HTML 结构
| 分值 | 描述 |
|------|------|
| 9-10 | 全局唯一 H1，H2/H3 正确嵌套，无跳级，导航与内容标题严格区分 |
| 7-8  | 基本结构正确，存在少量层级混用（如 H3 兼用于导航和内容区） |
| 5-6  | 标题层级混乱，H1 缺失或重复，但整体可辨识 |
| 3-4  | 大量 div/span 替代语义标签，AI 无法判断内容优先级 |
| 0-2  | 完全无语义结构，全页面仅有 div 和 span |

### 关键文字可爬取性
| 分值 | 描述 |
|------|------|
| 9-10 | 所有核心内容在 HTML 中预先静态写入，交互内容有降级文本 |
| 7-8  | 核心内容可读取，少量次要内容依赖 JS 加载 |
| 5-6  | 首屏关键内容 SSR，但重要区块（案例/历程/产品细节）依赖 JS Tab/轮播 |
| 3-4  | 多个核心区块均为纯 CSR，爬虫获取内容大幅缩水 |
| 0-2  | 页面为纯 CSR 空壳，爬虫落地几乎空白 |

### 页面层级清晰度
| 分值 | 描述 |
|------|------|
| 9-10 | 每个区块有明确语义标题，信息优先级一目了然 |
| 7-8  | 主要区块有标题，少数区块靠视觉而非语义区分 |
| 5-6  | 部分区块有标题，整体层级可辨但不清晰 |
| 3-4  | 大量区块无标题，AI 无法判断内容归属 |
| 0-2  | 完全平铺，无层级结构 |

### 图片 alt 文字覆盖率
| 分值 | 描述 |
|------|------|
| 9-10 | 全站信息性图片均有描述性 alt（Logo/产品图/团队照/案例图）；纯装饰图 alt="" 或省略 |
| 7-8  | 90%+ 信息性图片有 alt，少量次要图片缺失 |
| 6    | 主要图片有 alt，但合作伙伴/客户 Logo 等大量图片缺失 |
| 3-5  | alt 覆盖率 30%~60%，重要图片普遍缺失 |
| 0-2  | 几乎全无 alt，全站图片对 AI 不可见 |

### 链接文字语义质量
| 分值 | 描述 |
|------|------|
| 9-10 | 所有链接文字清楚描述目标页面内容（如"了解 Cyberklick 营销方案"） |
| 7-8  | 大多数链接有语义，少量使用"了解更多"等通用词 |
| 5-6  | 约一半链接有语义，剩余使用通用词 |
| 3-4  | 大量使用"点击这里"/"查看详情"/"路径"等无意义词 |
| 0-2  | 几乎全为无语义词，AI 无法理解页面关联关系 |

## 内容侧

### 公司描述事实密度
| 分值 | 描述 |
|------|------|
| 9-10 | 成立时间、总部、领域、规模、核心数字、上市信息等全部以可引用措辞呈现 |
| 7-8  | 包含大多数事实，措辞具体（如"累计服务超10,000家企业"） |
| 5-6  | 有基础事实但措辞模糊（如"丰富的服务经验"），或缺少关键信息 |
| 3-4  | 仅有公司名和大方向，缺乏可引用的具体数字或时间 |
| 0-2  | 全是"全球领先""行业第一"等空话，无可引用事实 |

### 可引用性
| 分值 | 描述 |
|------|------|
| 9-10 | 有原创深度报告/白皮书/含量化数据的详细案例；AI 可直接引用具体结论 |
| 7-8  | 有 1-2 篇高质量原创内容，或多个含部分数据的案例 |
| 5-6  | 有基础内容但深度不足，案例无量化数据 |
| 3-4  | 内容大多为宣传性文案，无原创洞察 |
| 0-2  | 无任何可引用深度内容，全为营销推广话术 |

### AI 友好摘要区块
| 分值 | 描述 |
|------|------|
| 9-10 | 有独立 /ai 页面，以问答/清单形式覆盖全部事实，且在 llms.txt 中索引 |
| 7-8  | 专属摘要区块（非独立页），含核心事实清单 |
| 4-6  | About 页包含大部分事实，但散落在多段文字中，AI 需自行拼凑 |
| 0-3  | 无专属摘要，全站信息高度分散 |

### 内容时效性
| 分值 | 描述 |
|------|------|
| 9-10 | 近 1 个月内有更新，新闻/博客持续发布，数据与当前一致 |
| 7-8  | 近 3 个月内有更新 |
| 5-6  | 近 6 个月内有更新，数据基本准确 |
| 3-4  | 超过 6 个月无更新，存在明显过期信息 |
| 0-2  | 超过 1 年无更新，或关键数据（数字/荣誉/合作伙伴）明显过时 |

## 技术侧

### llms.txt 部署
| 分值 | 描述 |
|------|------|
| 9-10 | 存在且内容完整：公司简介 + 核心页面索引 + 服务范围 + 联系方式 |
| 6-8  | 存在但内容不完整（缺少页面索引或服务描述） |
| 3-5  | 存在但内容极其空洞（仅一行或基本信息） |
| 0-1  | 404 确认未部署 |
| N/A  | 无法验证（403/超时），不扣分 |

### Schema.org 结构化数据
| 分值 | 描述 |
|------|------|
| 9-10 | Organization JSON-LD 部署完整，字段有实际值（name/url/foundingDate/address），附加 FAQ/Product 等 |
| 7-8  | Organization 基础字段齐全，无附加类型 |
| 4-6  | 有 Schema.org 但字段不完整或有占位符 |
| 1-3  | 有代码但结构错误（字段名拼错、嵌套混乱），实际无效 |
| 0    | 完全未部署 |

### Meta 标签质量（含 OG）
| 分值 | 描述 |
|------|------|
| 9-10 | title 含公司名+定位，description 事实性，og:title/description/type 均正确配置 |
| 7-8  | title/description 良好，OG 标签有配置但非所有页面 |
| 5-6  | title 可接受，description 模糊，OG 标签缺失或不完整 |
| 3-4  | title 仅有公司名，description 缺失，OG 完全未配置 |
| 0-2  | title/description/OG 全部缺失或配置错误 |

### 渲染方式
| 分值 | 描述 |
|------|------|
| 9-10 | SSR/SSG，爬虫落地即获取完整内容 |
| 7-8  | 主要内容 SSR，少量次要区块 CSR 延迟加载 |
| 4-6  | 部分 SSR 但核心内容区存在 CSR 延迟 |
| 0-3  | 纯 CSR（React/Vue/Angular 无服务端渲染），爬虫落地获取空壳 |

## 技术侧 — SEO 增量项

### title 字符长度
| 分值 | 描述 |
|------|------|
| 9-10 | 首页及所有核心页面 title 均在 50～60 字符内（中文按2字符），包含公司名+核心关键词 |
| 7-8  | 首页 title 长度合适，个别页面略长或略短 |
| 5-6  | title 存在但长度超过 70 字符或少于 20 字符，内容被截断或信息不足 |
| 3-4  | title 过长（>80字符）或内容重复（每页相同 title） |
| 0-2  | title 缺失或仅为网站名称无任何关键词 |

### meta description 质量
| 分值 | 描述 |
|------|------|
| 9-10 | 存在且 120～160 字符，内容事实性、具有区分度，包含核心关键词 |
| 7-8  | 存在且长度合适，但内容较通用 |
| 5-6  | 存在但过长（>160字符）或过短（<80字符），或内容为营销话术 |
| 3-4  | 存在但质量极差（如"欢迎来到XX官网"）或各页面相同 |
| 0-2  | 缺失，搜索引擎/AI 自动摘取正文，展示效果不可控 |

### URL 结构可读性
| 分值 | 描述 |
|------|------|
| 9-10 | URL 含语义化路径（`/about`/`/products`），无动态参数，无中文字符 |
| 7-8  | 大多数 URL 语义清晰，少量含无意义路径段（如 `/html/about`） |
| 5-6  | URL 结构可辨识但有冗余（如 `/html/performanceadvertising`），或含少量动态参数 |
| 3-4  | 大量动态参数（`?id=123&type=4`）或无语义路径 |
| 0-2  | URL 含中文字符（需转义）或随机数字串，无法被引用 |

### sitemap.xml
| 分值 | 描述 |
|------|------|
| 9-10 | 存在且可访问，包含全站核心页面，定期更新 |
| 7-8  | 存在且格式正确，但可能未包含所有页面 |
| 5-6  | 存在但格式错误或内容过时 |
| 0-2  | 404 确认不存在 |
| 不适用 | 无法验证（403/超时） |

### 内链与锚文字
| 分值 | 描述 |
|------|------|
| 9-10 | 核心页面之间有合理内链网络，锚文字含目标页面关键词 |
| 7-8  | 主要页面有内链，但部分锚文字使用通用词 |
| 5-6  | 有基础导航内链，但内容区域缺乏上下文内链 |
| 3-4  | 内链主要集中在导航，正文内几乎无内链 |
| 0-2  | 近乎孤岛式页面，几乎无互链 |

### viewport meta
| 分值 | 描述 |
|------|------|
| 9-10 | 所有页面有 `<meta name="viewport" content="width=device-width, initial-scale=1">` |
| 5-6  | 有 viewport 标签但配置非最佳（如固定宽度） |
| 0-2  | 缺失 viewport 标签 |
| 不适用 | 工具无法验证（markdown 模式不读取 head 标签） |

### OG image
| 分值 | 描述 |
|------|------|
| 9-10 | 配置 og:image，建议尺寸 1200×630px，每个核心页面有独立图片 |
| 7-8  | 有 og:image 但尺寸非最佳或所有页面共用同一张图 |
| 4-6  | 有 og:image 但分辨率过低或图片无法访问 |
| 0-3  | 未配置 og:image |
| 不适用 | 工具无法验证（markdown 模式不读取 head 标签） |
