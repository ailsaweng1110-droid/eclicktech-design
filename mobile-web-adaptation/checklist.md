# 逐页移动端自检清单

每个页面适配完成后，在 375px 与 768px 两个宽度下逐项核对。全部通过才算完成。

> **强制两轮**：Pass A = 本清单通读；Pass B = 实测（截图+量尺寸）并修好后再交付。**未做 Pass B 不得对用户说适配完成。** 用户再说「你再检查一遍」时应是例外，而不是默认质检方式。  
> 验证方式：不要只看整页缩略图。有可运行环境时，按约一屏高**分段截图**审查，并用脚本**量关键图片/元素在 375/1440 下的实际渲染宽高**、检测溢出（见 rules.md 第 12–13 节）。

## Pass B 高频漏项（第一轮最容易漏——交付前必过）

对照实测，不要只凭记忆打勾：

- [ ] **Logo 条 / 跑马灯**：375 下量过卡片宽高，明显小于桌面；非接近 `232×96` 的手机卡（rules 6.3）
- [ ] **合成图**：侧栏/插画不是整 section 截图；图内无与旁栏重复的可读文案（rules 6.4）
- [ ] **多层品牌标**：对照截图，叠放顺序正确（rules 6.5）
- [ ] **1440 重叠**：`absolute`+定宽区块标题完整可见，未被大图挡住（rules 5.1）
- [ ] **半展开双态**：切换后要点/正文真变了；桌面无多余手机 tab（rules 10.1）
- [ ] **轮播箭头**：点击会滚动或切页（rules 11）
- [ ] **主 CTA / 次级按钮**：手机主 CTA 全宽（若适用）；次级 `w-fit` 未被拉满
- [ ] **375 无页面级横滚**：`documentElement.scrollWidth <= clientWidth`
- [ ] **Pass B 发现问题已修好并复测**，不是只记在回复里

## 桌面端不被破坏（最高优先）
- [ ] 在 ≥1024px 宽度下，桌面渲染效果与适配前**像素级一致**
- [ ] 仅改动了默认（手机）与 `md:`（平板）断点的样式，未改变 `lg:`/`xl:` 桌面表现
- [ ] 为移动端修改基准值时已加 `lg:` 前缀锁定原桌面值，改动未向上泄漏到桌面
- [ ] **1440 抽检**：含绝对定位大图 + 定宽文案的区块无重叠、标题未被裁切（rules 5.1）

## 布局与容器
- [ ] 页面主容器使用统一边距 `px-4 md:px-6`；桌面有稿则 `lg:` 锁稿面 gutter，无稿用 `lg:px-8`；未把桌面大留白带到手机
- [ ] 375px 宽下无横向滚动条，无组件溢出视口
- [ ] 多列结构在手机变为单列（或合理的 2 列），未直接缩小桌面多列
- [ ] 横排图文在手机竖排堆叠，顺序符合信息优先级
- [ ] 桌面因窄卡片/多列而省略的正文，手机竖向空间充足处已补全（未照抄「仅标题」）
- [ ] 按断点显示不同内容时用 `lg:hidden`/`hidden lg:block` 控制显隐，未直接删 DOM（同时满足移动与桌面）
- [ ] **半展开双态**区块：手机为 tab/分段器且切换会换正文；桌面未硬加手机 tab（rules 10.1）

## 排版一致性
- [ ] H1、H2、H3、正文字号全站统一，本页与其他页面同层级大小一致（无一页大一页小）
- [ ] 正文 ≥ 16px，说明性小字 ≥ 14px，无更小字号
- [ ] 标题按断点缩小，未在手机出现超大标题挤压或难看换行
- [ ] 段落每行宽度适中（未超约 75 字符），长英文/URL 已 `break-words`

## 间距
- [ ] 区块垂直间距在手机收紧（如 `py-12`），层级仍清晰
- [ ] 元素/卡片间距不拥挤也不过空

## 图片与媒体
- [ ] 图片保持原始比例等比缩小（`w-full h-auto`），未被拉伸、变形或裁切
- [ ] **未裸写全局 `img { height:auto }`**；若有全局图片规则，已放进 `@layer base` 并排除自带尺寸类的图片（rules 6.1）
- [ ] 设了固定高度/铺满的图片（`h-*`/`h-full`/`size-full`）实际渲染尺寸正确，未塌陷成一条或撑爆
- [ ] 图标尺寸正确：方形用 `size-*`；非方形同时给宽高，无"只给一边 + `w-auto`"被撑到 ~300px（rules 6.2）
- [ ] **导出图标未按原尺寸撑满容器**：字形未被放大到填满整个外框（导出 SVG 常"紧裁到字形、丢了设计稿留白"）；已用「外框占位 + 字形缩到实际尺寸」还原（rules 6.2）
- [ ] **方向性图标（箭头/chevron）指向正确**：已核对设计稿该实例的 `rotate`，未直接用未旋转的基础素材导致指错方向（rules 6.2）
- [ ] Figma/工具导出的 SVG 已归一化（去 `preserveAspectRatio="none"`、按 viewBox 补显式宽高）
- [ ] 整幅媒体（hero/banner/地图）该满宽出血的已边到边，侧边距只留给文字容器
- [ ] **「文字烤进图片」的区块**：移动端未直接缩桌面大图导致图内文字过小/与页面标题重复；已用「无文字图 + HTML 实时标题」并按断点切换
- [ ] **未把整 section 合成图当单栏插画**；右栏图内无可读的左栏同款文案（rules 6.4）
- [ ] **Logo 条 / 跑马灯**：375 下卡片外框与字形明显小于桌面，`lg:` 已锁回稿面尺寸（rules 6.3）；量过一张卡的宽高
- [ ] **多层品牌标**叠放顺序与截图一致，可读作正确品牌名（rules 6.5）
- [ ] 大图使用响应式图源（`srcset`/`sizes` 或 Next `sizes`），手机加载小图但比例不变

## 按钮与触控
- [ ] 所有可点击元素触控区 ≥ 44×44px
- [ ] 主 CTA 在手机全宽，按钮组竖排且间距足够
- [ ] **行内/次级按钮**（查看更多/播放等）是自适应宽度靠左，未被写成 `w-full` 满宽
- [ ] **标签胶囊/badge** 在 flex 列里未被 `stretch` 拉满（已加 `w-fit`/`self-start`）；量渲染宽度确认非整行
- [ ] 表单输入字号 ≥ 16px（避免 iOS 缩放）

## 导航与公共组件
- [ ] 移动端导航为汉堡 icon，点击可正常展开/关闭
- [ ] 汉堡与菜单项触控区 ≥ 44px
- [ ] 导航、页脚为全站共享的同一组件，本页与其他页面一致
- [ ] 多级/hover 菜单在触摸端有点击替代

## 交互与兼容
- [ ] hover-only 效果（tooltip/下拉）在触摸端可用
- [ ] 轮播/拖拽支持触摸操作
- [ ] **轮播/跑马灯可见箭头已绑定滚动或切页**，不是装饰死箭头（rules 11）
- [ ] 存在 `<meta name="viewport" content="width=device-width, initial-scale=1">`
- [ ] `fixed`/`sticky` 头尾不遮挡内容，已处理 safe-area

## 一致性
- [ ] 本页所用断点、边距、字号、间距、公共组件与站内其他页面标准一致
