# 通用移动端适配提示词（可粘贴到任意 AI 建站工具）

这是一段自包含、工具无关的指令，可直接复制粘贴到 **Figma Make / Lovable / v0 / bolt / ChatGPT** 等工具的对话提示词、项目 Knowledge 或 Custom Instructions 中。用法：先让工具生成/完成桌面官网，再附上下面这段要求它做移动端适配（Figma Make、Lovable、v0 默认都是 React + Tailwind，示例可直接套用；若为原生 CSS，把类名换成等价 media query 即可）。

---

## 复制以下内容 ↓

请对当前网站做移动端适配，遵守以下统一规则。核心要求：**移动优先、重排而非等比缩小、全站各页标准一致、375px 宽下不得横向溢出。**

**最重要的约束——禁止改动桌面端样式**：只做移动端/平板适配，桌面端（≥1024px）的渲染效果必须与改前完全一致。只能新增/修改默认（手机）与 `md:`（平板）断点的样式；改动基准值时必须同步加 `lg:` 前缀锁定原桌面值（例：`grid-cols-3` → `grid-cols-1 md:grid-cols-2 lg:grid-cols-3`）。唯一例外是导航改汉堡菜单。完成后 ≥1024px 桌面须像素级一致。

**强制两轮质检（Pass A + Pass B）——不要等用户催「再检查一遍」**：
1. Pass A：按规则改完代码并通读自检清单。
2. Pass B（交付前必须做）：在 375 与 1440（建议再加 768）下分段看页面/截图，量关键元素实际宽高（logo 卡、主 CTA、图标），查横向溢出；重点复查——logo 条是否仍过大、是否误用整段合成图当插画、1440 是否图文重叠、双态切换是否真换正文、轮播箭头是否真能滚。
3. Pass B 发现问题立刻修好并复测；**未完成 Pass B 不得说适配完成**。

**断点**：手机 <768px（默认样式）、平板 768–1023px（`md:`）、桌面 ≥1024px（`lg:`）。按 375px 与 768px 两个宽度检查；有绝对定位大双栏时加测 1440。

**布局**
- 页面主容器统一：手机/平板 `px-4 md:px-6`；桌面有稿则 `lg:` 锁稿面 gutter（如 `lg:px-40`），无稿用 `lg:px-8`。勿把桌面大留白带到手机。
- 桌面多列在手机变单列：`grid grid-cols-1 gap-4 md:grid-cols-2 lg:grid-cols-3`；小卡片可 2 列。
- 横排图文在手机竖排：`flex flex-col md:flex-row`。禁止把桌面布局整体缩小。
- 表格在手机改卡片堆叠或横向滚动，不得撑破视口。
- 1920 稿的 `absolute`+定宽布局在 1440 易重叠 → 改 flex/grid 流式，或满稿仅放 `xl:`。
- 桌面半展开双态：手机用 tab 且切换换正文；桌面不加手机 tab。

**排版（全站统一，禁止 <14px）**
- H1、H2、H3、正文字号必须全站一致，同层级在每个页面用相同大小，不能一页大一页小。
- 正文 ≥16px（`text-base lg:text-lg`）；小字 ≥14px（`text-sm`）。
- H1/Hero `text-3xl md:text-5xl lg:text-6xl`，H2 `text-2xl md:text-3xl lg:text-4xl`，标题 `leading-tight`。

**间距**（按层级收紧，不等比缩放）
- 区块垂直间距 `py-12 md:py-16 lg:py-24`；元素间距 `gap-4 md:gap-6 lg:gap-8`；卡片内边距 `p-4 md:p-6`。

**图片（保持原比例）**
- 图片素材保持原始比例、等比缩小，禁止改变比例、拉伸或裁切变形。用 `w-full h-auto` 按宽度等比缩放。
- 大图用响应式图源（`srcset`/`sizes` 或框架的 `sizes`），手机加载小图但比例不变；纯装饰图可 `hidden md:block`。
- **整段合成图 ≠ 单栏插画**：若导出图已含标题/列表等 UI 文案，须裁切或按插画节点重导，禁止把整 section 截图塞进单栏导致文案重复。
- **Logo 条 / 跑马灯**：卡片外框与内部 logo 都要按断点缩小（如手机约 `h-14 w-[128px]`），桌面用 `lg:` 锁回稿面（如 `lg:h-24 lg:w-[232px]`）；禁止手机仍用接近桌面的大卡。
- **多层品牌标**：多片 SVG 须对照截图确认叠放顺序（常有几片要叠在同一槽），勿按文件名猜测。

**布局补充**
- 桌面若用 `absolute` + 定宽（按 1920 稿），在 1024–1919 易重叠裁字 → 改 `flex`/`grid` 流式，或满稿绝对布局仅放 `xl:`。
- 桌面「半展开双态」（一态全文 + 另一态仅标题）：手机改 tab/分段器，切换须换标题和要点；桌面不要硬加手机 tab。

**按钮与触控**
- 所有可点击元素触控区 ≥44×44px（`min-h-11`）；主 CTA 在手机全宽 `w-full md:w-auto`；**行内/次级按钮自适应宽度靠左**，别一律 `w-full`；按钮组竖排 `flex flex-col gap-3 md:flex-row`。
- 标签胶囊在 `flex-col` 里加 `w-fit`/`self-start`，防被拉满整行。
- 表单输入字号 ≥16px 避免 iOS 缩放；可点元素间距 ≥8px 防误触。
- 轮播/跑马灯上的可见箭头必须能滚动或切页，禁止装饰用的死箭头。

**导航与公共组件**
- 移动端导航用汉堡 icon，点击展开抽屉/全屏菜单（桌面链接 `hidden md:flex`，汉堡按钮 `md:hidden`）；移动端导航样式与桌面不同是预期的。
- 汉堡与菜单项触控区 ≥44px；多级/hover 菜单在触摸端改为点击展开，不依赖 hover。
- 导航、页脚等公共组件全站复用同一个组件，每页保持一致，只改一处全站生效。

**内容顺序**
- 移动端按重要性重排，核心信息与主 CTA 上移。桌面「图左文右」在手机按优先级决定「文上图下」或反之。
- 桌面因窄卡省略的正文，手机应补全；断点显隐用 `lg:hidden`/`hidden lg:block`，勿删 DOM。

**适配后自检并修复**
- **先做完 Pass B 再交付**：375/1440 分段看图或量尺寸；logo 条、合成图、1440 重叠、双态、轮播箭头等第一轮易漏项必须过完；有问题当场修并复测。
- ≥1024px 桌面与改前像素级一致；**另抽检 1440**：绝对定位大图区块无重叠裁字。
- 375px 下无横向滚动、无溢出；固定宽度 `w-[600px]` 改 `w-full max-w-[600px]`；长英文/URL 加 `break-words`。
- 量过 logo 卡与关键图标实际渲染宽高；图片保持原比例未变形；内容不拥挤。
- hover 交互在触摸端有点击替代；轮播支持触摸且箭头可用。
- 存在 `<meta name="viewport" content="width=device-width, initial-scale=1">`；`fixed`/`sticky` 头尾不遮挡内容并处理 safe-area。
- 全站每个页面都用同一套断点、边距、字号、间距、公共组件标准，保持一致。

## 各工具使用建议

- **Figma Make**：先描述并生成桌面官网，再在下一轮对话贴入上面这段；或在项目说明中长期保留。指令较长时可分批贴（如先只贴导航+图片部分），效果更稳。
- **Lovable**：放进项目的 Knowledge / Custom Instructions，长期生效；也可在具体某页返工时单独贴。
- **v0 / bolt**：作为 system prompt 或每次附带。
- **Cursor**：无需粘贴，直接触发 `mobile-web-adaptation` skill 即可。
